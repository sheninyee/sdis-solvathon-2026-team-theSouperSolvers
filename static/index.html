    How Federal Funds Matchmaker scores opportunities

    Each grant is ranked by a weighted combination of five signals. Scores are advisory only — your team makes the final call.

    SignalWeightWhat it measures
    🧠 Semantic relevance45%Cosine similarity between NCDOT's mission text and the grant synopsis, computed with Azure OpenAI embeddings.
    🔑 Keyword match25%TF-IDF overlap between grant text and NCDOT's search seed keywords (bridge, transit, safety, EV, rural access, etc.).
    ✅ Eligibility15%Rule-based check: does the grant's listed applicant types include state governments? No LLM involved — deterministic logic only.
    ⏱ Timing10%Proximity to close date. Grants closing within 30–90 days score higher; forecasted grants score lower.
    🏛 Funder affinity5%Preference for USDOT, FHWA, FTA, and other historically relevant federal agencies.

    Confidence rating

    High — full synopsis text available; both semantic and keyword signals are reliable.
    Medium — partial text; keyword signal used, semantic may be estimated.
    Low — minimal source text; score is a rough estimate only.

    Effort estimate

    Estimated based on text signals: cost-share requirements, award size ≥ $10M, multi-year scope, consortium/partnership language, and NEPA review mentions. Not AI-generated — deterministic rule-based logic.

    AI use disclosure

    Semantic scoring (45%) uses Azure OpenAI text-embedding-3-small to compute vector similarity. The optional AI summary (shown in grant details) uses Azure OpenAI GPT-4.1-mini to synthesize a plain-English overview from public grant text. Eligibility verdicts and effort ratings are rule-based and do not use AI. No grant facts are invented — if information is unavailable, the tool displays "not stated."

    When AI embeddings are unavailable, the tool falls back to keyword-only scoring and displays a warning banner.

    Source: Grants.gov
